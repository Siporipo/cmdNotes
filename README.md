# cmdNotes
## Product specifications
cmdNotes is a Linux exclusive for the time being because of the development environment and, more importantly, use of the realpath() function.
## Installation Guide
All you need is the binary executable `notes` and the .txt `notehelp.txt` from the repository's bin/ directory. Download them and keep together. You might want to put them in the /bin/ directory for ease of use (`notes <args>` instead of `./pathtonotes/notes <args>`)
